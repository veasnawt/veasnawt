## Current focus

- **Make VCut dependable:** improve stability, exports, and the first-time editing experience.
- **Grow Pinly:** help people discover interesting content connected to the world around them.
- **Keep learning through VOS:** build and test low-level systems, one milestone at a time.
- **Contribute to open source:** create reusable tools and share what can help other developers.
